# Redis Eats Promo Code Policy

## Overview

Redis Eats offers promotional codes (promo codes) as a way to reward customers, encourage new sign-ups, and support special campaigns. This policy explains how promo codes work, how to apply them, and what restrictions apply.

---

## What Are Promo Codes

Promo codes are alphanumeric codes that customers can enter at checkout to receive a discount on their order. Discounts may include:

- A fixed dollar amount off the order subtotal (e.g., $5 off)
- A percentage discount on the order subtotal (e.g., 20% off)
- Free delivery on a specific order
- A combination of the above

---

## How to Apply a Promo Code

1. Add items to your cart and proceed to checkout.
2. On the checkout screen, look for the **Promo Code** or **Add a Code** field.
3. Enter your code exactly as provided (codes are not case-sensitive).
4. Tap **Apply**. The discount will appear in your order summary before you confirm.

If the code does not apply, see the Troubleshooting section below.

---

## Promo Code Restrictions

Most promo codes come with restrictions. Common restrictions include:

- **Minimum order amount:** The code only applies if your subtotal meets a minimum threshold (e.g., orders over $15).
- **First order only:** Some codes are valid only for a customer's first Redis Eats order.
- **Single use:** Many codes can only be used once per account.
- **Expiration date:** All codes have an expiration date. Expired codes will not be accepted.
- **Specific restaurants:** Some codes apply only to orders from designated restaurant partners.
- **Geographic restrictions:** Codes may be valid only in certain cities or regions.

The specific restrictions for a code will be shown when you apply it at checkout.

---

## Promo Code Combinations

Only **one promo code** can be applied per order. Promo codes cannot be combined with each other. However, promo codes can generally be used alongside:

- Redis Eats subscription benefits (if applicable)
- Loyalty rewards credits

---

## Referral Codes

Redis Eats offers a referral program. When you refer a friend:

- Your friend receives a discount on their first order.
- You receive Redis Eats Credit after your friend completes their first order.

Referral credits are subject to the same expiration and usage rules as other credits. Abuse of the referral program (such as creating fake accounts) may result in account suspension.

---

## Troubleshooting Promo Codes

If your code is not working, check the following:

| Issue | Possible Cause |
|---|---|
| "Code not found" | The code was entered incorrectly. Check for typos or extra spaces. |
| "Code expired" | The code's expiration date has passed. |
| "Code already used" | You have already used this single-use code. |
| "Minimum order not met" | Your subtotal is below the required minimum. Add more items. |
| "Not valid for this restaurant" | The code applies only to specific restaurants. |

If none of the above apply and your code still will not work, contact Redis Eats Support.

---

## Promo Code Abuse

Redis Eats monitors for promo code abuse, including:

- Creating multiple accounts to use single-use codes repeatedly
- Sharing codes that are not intended for public distribution
- Applying codes to orders that do not meet the qualifying criteria

Accounts found to be abusing promo codes may have their promotional privileges removed or their account suspended.
